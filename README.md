# NFS Underground 2 — Widescreen Fix

A widescreen fix package for Need for Speed: Underground 2 (PC).

## Installation

1. Download the ZIP file from the Releases section.
2. Extract `NFSU2-Widescreen-Fix.zip`.
3. Open the extracted folder.
4. Copy the included `scripts` folder into your Need for Speed: Underground 2 game directory.
5. If a `scripts` folder already exists, merge the folders and keep the existing files.
6. Make sure the `scripts` folder is located next to `SPEED2.exe`.
7. Launch the game and check whether the widescreen fix works correctly.

## Folder structure

Your game directory should look like this:

    Need for Speed Underground 2/
    ├── SPEED2.exe
    └── scripts/
        ├── NFSUnderground2.WidescreenFix.asi
        ├── NFSUnderground2.WidescreenFix.dat
        └── NFSUnderground2.WidescreenFix

*The exact files may vary depending on the version of the fix.*
